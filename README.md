# Online Learning Management System (LMS)

## Overview
A web-based Learning Management System developed using PHP and MySQL. The system provides separate workflows for students and faculty and supports common academic activities such as course management, enrollment, assignments, examinations, and learning content.

## Features
- Student and faculty registration/login
- Course creation and enrollment
- Assignment management
- Online examinations and quizzes
- Lecture and course content management
- Student participation and academic records
- Relational database integration

## Technologies
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Database
The system uses a relational MySQL database for managing users, courses, enrollments, assignments, examinations, questions, and other academic records.

To run the project locally:
1. Import `online_learning_portal.sql` into MySQL/phpMyAdmin.
2. Update the database configuration in `dbConnection.php` if necessary.
3. Place the project folder inside your local web server directory (e.g., `htdocs` for XAMPP).
4. Start Apache and MySQL.
5. Open the project through `localhost` in your browser.
